# FRAME//SHIFT — Motion & AI Studio Website

An original, self-contained one-page studio website inspired by the cinematic pacing and editorial confidence of high-end AI/film studio websites, without copying VELUM's brand, wording, assets or exact layouts.

## Included
- Cinematic loading sequence with progress animation
- Generative canvas hero background
- Large editorial typography and live timecode motif
- Fixed navigation, custom cursor and scroll progress
- Infinite marquee strip
- Scroll-triggered reveals
- Three original concept project visuals made entirely with CSS
- Magnetic CTA interactions and 3D project-card tilt
- Responsive layouts for desktop, tablet and mobile
- Reduced-motion accessibility support

## Run
Open `index.html` directly in a modern browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Customize
Search and replace:
- `FRAME//SHIFT` with your brand name
- `hello@frameshift.studio` with your email
- Mumbai / Dubai with your locations
- Project names and copy in `index.html`
- Accent colors in the CSS `:root` variables

No external libraries or third-party assets are required.
