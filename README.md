# CK Filmz — Phase 1 Portfolio Website

A production-ready Phase 1 website for CK Filmz: portfolio, services, inquiry form, WhatsApp contact and cinematic visual identity.

## Current purpose
- Showcase public work
- Present services on a “price on request” basis
- Capture project inquiries
- Keep the same cinematic dark UI direction from the original prototype

## Included
- Animated loading sequence
- Generative canvas hero background
- Portfolio cards using public YouTube thumbnails and links
- Service rows for AI visuals, lead generation, videography, drone filming, product shoots, social content, editing and color grading
- Netlify-compatible inquiry form
- WhatsApp CTA
- Responsive layouts
- Reduced-motion accessibility support
